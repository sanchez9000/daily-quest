# Daily Quest

A private calendar with month, week, day, and agenda views. It looks like a normal calendar, but events come from your own API instead of Google.

It runs in the browser and can be installed on Android, iPhone, iPad, Mac, Linux, and Windows.

## Run

```bash
npm install
npm run dev
```

Open Settings to set the server URL, auth, and whether calls go direct or through the relay.

Schedules stay on this device until you connect a server. Demo events are seeded so the calendar is not empty.
